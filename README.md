# 🌍 World Map News

> Explore notícias do mundo inteiro através de um mapa interativo.

**World Map News** é uma aplicação web interativa que permite explorar notícias globais por localização e categoria. Selecione um país no mapa e descubra as notícias e acontecimentos mais recentes daquela região.

### 🚀 Live Demo

**[world-news-map-ten.vercel.app](https://world-news-map-ten.vercel.app)**

---

## ✨ Features

- 🌍 **Mapa-múndi interativo** — explore países diretamente pelo mapa
- 📰 **Notícias em tempo real** — integração com a GNews API
- 🎯 **Categorias** — Política, Economia, Tecnologia, Entretenimento, Esportes, Ciência e Saúde
- 🔎 **Exploração por país** — selecione uma região para visualizar sua cobertura
- 📱 **Responsive** — experiência adaptada para desktop e mobile
- 🌑 **Dark UI** — interface minimalista com estética editorial
- ⚡ **Performance** — desenvolvido com Next.js e otimizações modernas

---

## 🛠️ Tech Stack

| Tecnologia | Uso |
|---|---|
| **Next.js 16** | Framework |
| **React 18** | Interface |
| **TypeScript** | Linguagem |
| **Tailwind CSS 4** | Estilização |
| **react-simple-maps** | Mapa interativo |
| **D3.js** | Visualização do mapa |
| **SWR** | Data fetching e cache |
| **Lucide React** | Ícones |
| **GNews API** | Notícias |

---

## 📸 Como funciona

1. Abra o **World Map News**
2. Explore o mapa-múndi
3. Clique em um país
4. Visualize as notícias daquela região
5. Filtre por categoria
6. Abra a notícia na fonte original
